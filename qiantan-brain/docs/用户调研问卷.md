# 用户调研问卷——菜市场小微商户经营现状

> 📌 用于大创立项的"需求研究"环节。目标是收集 50-100 份有效样本，作为"需求真实存在"的证据，弥补无法直接深度接触摊主的局限。
>
> **发放方式**：问卷星 / 腾讯问卷 / 金山表单均可，通过团队成员朋友圈、同学家人转发，瞄准有过小生意/摆摊/菜市场主体接触的受访者。
>
> **填写说明**：问卷已按"基本信息 → 经营现状 → 记账习惯 → 工具接受度 → 开放题"五段式设计，预计填写时长 5-8 分钟。所有题目均基于项目真实功能场景设计，数据可直接用于立项书的"用户痛点"章节佐证。

---

## 卷首语

您好！我们是【学校名称】的大学生创新创业团队，正在研究一款帮助菜市场/早市摊主更轻松记账和经营的智能工具。为了让工具真正贴合您的需要，我们希望了解您的真实经营情况与遇到的困难。

问卷大约需要 5 分钟，**所有信息仅用于学术研究，完全匿名，不会泄露给任何第三方**。非常感谢您的帮助！
