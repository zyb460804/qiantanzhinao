# 千摊智脑 · 设计系统 v5.0「鲜 · 晨光菜市」

> 2026-09 全量重设计。旧 v4.2「市井账本风」的**类名与令牌名作为 API 全部保留**，
> 视觉语言、组件与动效整体重做；页面层零改动即可全局换新。

---

## 一、设计方向

**一句话**：一张摊位上的新鲜账本——鲜青菜绿是主导色，价签红管金额与警示，
麦穗金管利润与目标；hero 是「傍晚菜场的灯箱」，卡片是白瓷纸面，
签名元素是**小票撕边卡、虚线撕线、价签红印章**，金额一律宋体数字。

给 40-50 岁摊主的工具，克制但精致；氛围与光效只出现在主 CTA / hero / FAB，
绝不全屏铺张。

## 二、五个组件库各学了什么

| 来源 | 学到的 | 落地方式 |
|---|---|---|
| shadcn/ui | 语义 token 层（--primary/--border/--ring…）、hairline 边框 + 双层阴影、组件克制 | `page` 下的 shadcn 语义别名层；卡片/按钮/徽章全部重做 |
| Radix UI | 弹层与表单的交互语义 | `.dialog` 重做；新增 `.sheet` 底部弹层（mask + grabber + slide-up）；输入框 focus 品牌环 `--focus-ring` |
| Aceternity UI | 氛围与光 | hero 灯箱（渐变 + 顶部柔光 + 点阵纹理）；`.btn--sheen` 扫光；`.card--lift` 浮起 |
| Magic UI | 一键复制的动效组件 | 全部纯 CSS：`rise-in` 入场编排、`fab-glow` 呼吸辉光、骨架流光 |
| Tremor | 数据展示模式 | `.stat-card` + `.mini-bars`（近 7 日趋势柱）+ `.progress` 进度条 |
| HeroUI / 其它 | 未采纳的部分 | 紫色渐变、玻璃拟态、重动效——与摊主群体和 WXSS 约束不符，明确不做 |

另有 GitHub 上最火的 **Anthropic `frontend-design` skill** 的方法论贯穿本次重设计：
先定一个大胆且贴上下文的方向，再以精度执行；动效优先做「一次编排好的入场」，
而非散落的微交互；背景要有氛围而不是纯色。

## 三、设计语言

### 色彩（物理令牌，页面直接可用）

| 角色 | 令牌 | 值 |
|---|---|---|
| 画布 | `--canvas` | `#f3f5f1` 浅灰绿 |
| 纸面 | `--paper / --paper-2 / --paper-3` | `#ffffff / #f7f8f5 / #eaede6` |
| 墨色 | `--ink / --ink-2 / --muted` | `#17201a / #4a554e / #87918a` |
| 主色 | `--green-700`（primary） | `#1b7a44` 鲜青菜绿 |
| 警示/金额 | `--tomato`（+`-soft/-ink/-600`） | `#d93a2b` 价签红 |
| 利润/目标 | `--corn`（+`-soft/-ink/-600`） | `#d99a26` 麦穗金 |
| 角色色 | `--info / --grape`（+soft/ink） | 信息蓝 / 紫罗兰 |

绿色 11 阶：`--green-950 … --green-50`；深色模式在 `.ui-dark` 下整组重定义。

### shadcn 语义别名层

`--primary / --primary-foreground / --secondary / --accent / --destructive /
--border / --input-bg / --muted-foreground / --focus-ring / --card / --background / --foreground`
全部映射物理令牌，两套词汇表任选。

### 字体

- 展示/正文：PingFang SC 系
- **金额数字：宋体**（`--font-num`，Songti/Noto Serif SC）——价签感，是整个系统的记忆点
- 字号阶梯：`--fs-xs 20 / sm 23 / base 28 / lg 32 / xl 38 / 2xl 46 / 3xl 58 / hero 84`（rpx）

### 圆角 / 阴影

- 圆角：`--r-sm 10 / md 14 / lg 20 / xl 28 / pill`——白瓷器，挺括不软糯
- 阴影：双层（环境光 + 主光）`--shadow-sm/--shadow/--shadow-lg`；品牌辉光 `--glow-primary`

### 动效政策

| 层级 | 内容 | 开关 |
|---|---|---|
| 常开 | 按压回弹、switch/progress 过渡、骨架流光、pop-in | 默认 |
| 入场编排 | `.rise`（页头）+ `.stagger--on`（列表逐项，6 级延迟） | 按页挂类 |
| 氛围光 | `.btn--sheen` 扫光、`.fab--pulse` 呼吸辉光 | 只允许主 CTA / FAB |
| 无障碍 | page 根节点挂 `reduce-motion` 全部关停，且入场元素强制可见 | `.reduce-motion` |

**v5.6 原生 canvas 全退役**（雷达真机浮层事故后的根治）：
- 全项目 4 处 canvas 全部转纯 CSS/WXML，小程序内**不再有任何 canvas**：
  1. `stock-chart` 组件 → WXML 横条列表（props API 不变，observer 归一化行数据）
  2. `finance` 月度收支 → `.fin-bars` 横条（负项红条，正项绿条）
  3. `report` 营业趋势 → `.trend-bars` 分组柱（营业额绿柱 + 毛利金柱，日/周/月通用，30 日自动细柱）
  4. `sandbox` 方案对比 → `.scheme-bars` 横条（最优方案加深描边，负收益红条）
- `utils/chart.js` 已无页面引用（文件保留）；`risk-gauge` 组件无引用（文件保留）
- 副产物：report 趋势图例去掉「客单价」（分组柱表达不了第三系列，客单价在 KPI 卡已有）
- **经验：小程序图表默认用 CSS 条/柱/环，canvas 只在 CSS 真的画不出来时才上（且必须包 position:relative 容器）**

## 五、主题机制

- **时段皮肤**：根视图 `skin-morning/noon/evening` → 覆盖 `--skin-accent/glow/ambient/label`；`utils/theme.js` 的 `Theme.apply(this)` 一站式接入
- **深色模式**：根视图 `ui-dark`，整组令牌切到绿黑
- **减动效**：根视图 `reduce-motion`
- 页面根节点写法：`<view class="page-shell skin-{{skin}} {{dark?'ui-dark':''}} {{reduce?'reduce-motion':''}}">`

## 六、工程约束（wxss_lint.py 强制）

- 禁 `@media` / `:root` / `*` 通配 / `vh·vw·rem` / 本地 `url()`
- 变量一律定义在 `page { }`；新页面只用令牌不写死色值
- 改令牌即全局换肤；类名是页面 API，废弃需走兼容层
