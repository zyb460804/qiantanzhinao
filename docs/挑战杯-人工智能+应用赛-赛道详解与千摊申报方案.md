## 一、它到底是什么

### 1.1 法律定位

《"挑战杯"全国大学生课外学术科技作品竞赛章程》**第二十六条**：

> 全国组织委员会配套举办"揭榜挂帅"专项赛……；举办"人工智能+"专项赛，鼓励中外青年学生联合组队参赛，深入探索并挖掘人工智能的创新应用潜力。专项赛事（活动）具体方案由全国组委会制定。

所以它**与挑战杯主体赛（自然科学类论文 / 哲社类调查报告 / 科技发明制作）平行**，是第二条独立赛道，由全国组委会单独制定方案、单独评审、单独授奖。

### 1.2 设立目的（方案原文）

> 促进人工智能与经济发展、社会民生深度融合，培养一批既懂人工智能技术又熟悉行业发展的复合型人才，助力培育发展新质生产力。

关键词是 **"深度融合"** 和 **"复合型人才"**——评委想看的是"你真的把一个行业问题用 AI 解决了"，不是"你调了个大模型 API 做了个 demo"。

### 1.3 应用赛道定位（方案原文）

> 本赛道鼓励广大参赛者既瞄准国家重大战略需求与科技前沿问题，又从保障和改善民生、为人民创造美好生活的需要出发，充分利用自身所学所长，助力人工智能技术与各行业深度融合的"人工智能+"向纵深发展。

拆成三个评分暗示：

| 维度 | 含义 | 千摊对应 |
|---|---|---|
| **国家重大战略 / 科技前沿** | 人工智能+ 行动、新质生产力、数字经济 | 边缘 AI 下沉到 2000 万小微摊贩 |
| **保障和改善民生** | 真实痛点、普惠、弱势群体 | 低学历/高龄摊主的零门槛数字工具 |
| **与行业深度融合** | 不是通用 demo，是踩进具体业务流程 | 语音记账→库存→POS→AI 参谋→追溯全链路 |

## 二、三个子赛道，别选错

| 子赛道 | 定位 | 作品形式 | 千摊适配 |
|---|---|---|---|
| **创意赛** | 开放式创意赛道，注重创新创意；**借助大模型技术，通过零代码或低代码**完成 AI 原生应用的设计、开发和线上运行 | 项目策划书 + 项目视频介绍 + **作品线上链接** | ❌ 不适合。千摊是全栈自研 + 边缘硬件，报创意赛等于自废武功 |
| **应用赛** | 面向国家战略与民生需求，AI 与各行业深度融合 | 项目介绍和展示材料 + 佐证材料；须能通过**视频或图文全方位展现** | ✅ **推荐** |
| **挑战赛** | 由 AI 领域企业和科研机构提出"卡脖子"难题，青年集智破题 | 按各题目要求完成；题目在**"创青春"公众号**发布 | ⏸ 需等榜单选题，被动 |

> ⚠️ **三个子赛道只能选一个，且不得同时参加主体赛。**

## 三、参赛资格（这是它最大的优势）

| 项目 | 应用赛 | 主体赛（对照） |
|---|---|---|
| 学历 | 专科 / 本科 / 硕士 / **博士** 均可（均不含在职） | 专科 / 本科 / 硕士，**无博士** |
| 注册时间 | 决赛当年 6 月 1 日前正式注册的全日制非成人教育高校在校生 | 同 |
| 组队 | 个人或团队，**每团队 ≤10 人**（含作品申报者） | >3 人须报集体作品，作者须均为学生 |
| 跨校 | ✅ **可跨专业、跨学校、跨地域组队** | ❌ 不支持跨校 |
| 年龄 | **40 周岁以下**（1985.6.1 含以后出生） | 无明文 |
| 指导教师 | 每件 ≤3 名 | ≤3 名，**且须 2 名高级职称推荐** |
| 高校名额 | ✅ **各高校申报作品总数不限** | ❌ 每校 ≤6 件 |
| 推报 | **不限名额择优推报**国赛 | 名额由主办单位统一确定 |

**学历认定细则**（与主体赛一致）：
- 硕博连读（直博）生：决赛当年 6 月 1 日前**未通过**博士资格考试 → 按硕士申报；通过 → 按博士申报
- 无资格考试制度的学校：前两年按硕士，后续按博士
- 本硕博连读：按四年、二年及后续分别对应本、硕、博

**额外鼓励**：支持**中外青年联合组队**，鼓励有国外学籍的外籍学生、中国籍海外留学生与国内学生联合组队。

## 四、选题方向（官方 9 个参考方向）

```
1. 人工智能+ 农业发展      6. 人工智能+ 环境保护
2. 人工智能+ 工业制造      7. 人工智能+ 政务管理
3. 人工智能+ 医疗健康      8. 人工智能+ 文化旅游
4. 人工智能+ 教育教学      9. 人工智能+ 其他综合领域
5. 人工智能+ 交通运输
```

### 千摊智脑的两种挂法

**主推：9「其他综合领域」** —— 小微商贸流通、地摊经济、个体户数字化，官方没有专门类目，归口综合领域最稳妥。

**备选叙事：1「农业发展」** —— 如果能把叙事重心放到"农产品从田间到摊位流通环节的损耗治理"（损耗率 15%-30% → 降 5-10 个百分点），就能贴上"人工智能+农业"标签，战略契合度更高，更容易被评委认为"踩在国家需求上"。

> 建议：**正文走综合领域，摘要和答辩开场用农业/食品安全叙事破题**，两头都占。

## 五、作品要求与提交材料

### 5.1 官方要求（方案原文）

> 需提交**项目介绍和展示材料、佐证材料**等。作品（实物或者技术）须能通过**视频或图文形式全方位展现**。

### 5.2 系统实际上传项（应用赛指导手册）

1. **作品信息**（按系统左栏导航逐项填，红色星号为必填页）
2. **项目策划书**（独立上传项）
3. **附加材料**（项目介绍、展示材料、佐证材料）
4. 提交（**提交后不可自行修改**）

### 5.3 建议材料清单（针对千摊）

| 材料 | 内容要点 | 优先级 |
|---|---|---|
| **项目策划书** | 背景痛点、技术方案、创新点、应用成效、推广前景 | P0 |
| **演示视频**（3-5 分钟） | 语音记账 → 拍照识别入库 → POS 收银 → AI 参谋建议 → 扫码追溯，全流程实机 | P0（方案明确"须能通过视频展现"） |
| **研究报告** | 架构图、数据流图、模型指标表、试验数据 | P0 |
| **技术佐证** | YOLOv8-nano 混淆矩阵/mAP、Prophet 预测误差（MAPE）、语音解析准确率、边缘推理时延 | P0 |
| **落地佐证** | 试点摊位数量、使用时长、损耗率对比、用户反馈/采纳证明 | P1（区分度最大） |
| **知识产权** | 软著登记证书 / 专利受理通知书 | P1 |
| **外观与结构图** | 树莓派终端实物照、系统架构图、小程序界面截图 | P1 |

## 六、申报全流程（系统操作）

### 6.1 报名链路

```
官网注册（用户名必须是邮箱）
   ↓
导航栏「比赛入口」→「加入比赛」
   ↓
「我上报的作品」→「创建作品」→ 同意授权（不同意无法继续）
   ↓
按左栏导航填写作品信息（红星必填）
   ↓
上传项目策划书 → 上传附加材料
   ↓
提交（⚠ 提交后不可修改，只能等管理员打回）
   ↓
查看激活码（在「作品情况概览表」中）
```

**激活码资源**（免费，一定要领）：
- 科大讯飞**星火大模型**资源
- 红山开源与启元实验室**大模型算力**资源

### 6.2 三级审核

| 环节 | 主体 | 动作 |
|---|---|---|
| 校级审核 | **学校团委**管理员（账号由团省委下发，不是学院） | 通过 / 不通过 / **预通过**（打回学生修改，状态变为「审核预通过，信息不完整」） |
| 省级审核 | 团省委管理员 | 通过 → 推送国赛 / 不通过 / 预通过打回 |
| 省级排序 | 团省委 | 全部申报审核完成后，**根据作品质量排序，择优推报** |

校级管理员还需下载作品汇总表 → **盖章扫描 → 上传系统**。

> 💡 **实操提示**：应用赛**不走学院名额通道**（主体赛才走，见附件2 各学院推荐项目数）。它是团委口，找学校团委要校级管理员账号体系下的申报入口即可。

## 八、评审与奖励

### 8.1 奖励比例

| 等级 | 占比 |
|---|---|
| 特等奖 | ≤ 10% |
| 一等奖 | ≤ 20% |
| 二等奖 | ≤ 30% |
| 三等奖 | 其余 |

对照主体赛（特 5% / 一 10% / 二 20% / 三 55%）——**应用赛的高等级奖占比是主体赛的两倍**。

### 8.2 关于评分标准

官方公开文件**未披露细化评分表**（指导手册只有系统操作流程，无评审细则）。依据方案的三段式定位（国家战略 / 民生需求 / 行业深度融合），建议按以下四维修炼：

1. **战略契合度** —— 是否踩在"人工智能+"行动、新质生产力、普惠金融/食品安全等政策语境上
2. **民生价值** —— 受益人群规模与真实痛点强度（千摊：2000 万小微摊贩，这个数字很有杀伤力）
3. **技术纵深** —— 是否真的用了 AI（CV + 时序预测 + 语义解析三重，而非单一 LLM 调用）
4. **落地实证** —— 有没有真实数据、真实用户、真实采纳证明（**这一项是最容易拉开差距的**）

## 十、千摊智脑申报方案建议

### 10.1 作品题目（≤30 汉字，参考）

- 主推：**《千摊智脑：面向小微摊贩的环境感知型 AI 经营智能体》**（24 字）
- 农业叙事版：**《千摊智脑：基于边缘视觉与时序预测的农产品流通减损系统》**（27 字）

### 10.2 核心叙事（三段式）

1. **痛点**：2000 万小微摊贩，损耗率 15%-30%，现有进销存 ¥3000+ 且操作复杂，用不起也不会用
2. **方案**：¥500 以内硬件（树莓派 5 + CSI 摄像头 + HX711）+ 微信小程序 + 云端 AI，一句话语音记账、拍照即入库、天气+销量预测给进货建议
3. **价值**：零学习成本（语音交互，初中文化可用）、硬件门槛降 90%、损耗预计降 5-10 个百分点、食品安全批次可追溯

### 10.3 与赛道的三重咬合

| 赛道要求 | 千摊的对应证据 |
|---|---|
| AI 与行业深度融合 | CV 识别 + NLP 语义解析 + Prophet 时序预测 + 差分隐私经验云，四重 AI 嵌进真实经营闭环 |
| 保障和改善民生 | 面向低学历/高龄群体的普惠设计，缩小数字鸿沟 |
| 国家战略 | 地摊经济/夜市经济、食品安全治理、数字乡村与农产品流通 |

### 10.4 现在最该补的三件事（按优先级）

1. **真实试点数据** —— 2-3 个摊位跑 2-4 周，拿到「使用前/使用后损耗率对比」，这是最硬的佐证
2. **演示视频** —— 方案明文要求"须能通过视频或图文全方位展现"，实机全流程录像是刚需
3. **软著/专利受理号** —— 提报周期短，性价比高

### 10.5 与主体赛 B 类怎么选

| 维度 | 主体赛科技发明制作 B 类 | 人工智能+ 应用赛 |
|---|---|---|
| 名额 | 走学院，计算机与信息学院 20 个 | **不限名额** |
| 指导老师 | **须 2 名高级职称** | ≤3 名，无强制职称 |
| 组队 | 限本校学生 | **可跨校跨地域，≤10 人** |
| 高等级奖占比 | 特 5% / 一 10% | **特 10% / 一 20%** |
| 材料 | 申报书 D 表 + 研究报告 | 项目策划书 + 展示材料 + 佐证材料 |
| 含金量认可度 | 传统、认可度高 | 新赛道，但上升快 |

**建议**：
- 若**已有 2 名高级职称老师 + 团队全在校内** → 两者都行，B 类更"正统"
- 若**缺高级职称导师 / 想跨校 / 学院名额竞争大** → 果断选**应用赛**
- 两条路材料可复用约 80%（研究报告、技术对比、演示录像、试点数据通用），差别只在申报表与提交入口
